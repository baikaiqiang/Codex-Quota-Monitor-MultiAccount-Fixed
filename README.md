## ✨ 两大亮点

### 📊 亮点一：额度实时监控

一只蹲在任务栏边上的小猫咪，帮你实时盯着 Codex 额度：

- 🍩 所有额度桶的剩余 / 已用百分比，主窗口、次窗口都看得见
- ⏰ 重置倒计时——离刷新还有多久，一目了然
- 📦 套餐、Credits、个人支出控制、服务端限制、重置券，全部汇总
- 📈 累计 / 今日 / 本周用量，还能和上一个周期对比，知道自己是变省了还是变浪了
- 🐢🚀 按你的真实用量估算"平均速度"和"预计还能撑多久"，该省的时候提醒你，该放心用的时候让你放心用

### 👤 亮点二：多账号一键切换（本次修复）

- 👤 多账号总览：每个账号首次走官方网页登录，之后自动缓存刷新
- 🔄 组件内一键切换登录状态，不用反复登出登入
- 🖥️ 一键重启官方 Codex 桌面版，切换后即刻生效
- ✅ **本次修复**：解决了原版中多账号登录切换失败的问题，切换流程现在稳定可用

### 🔒 安全承诺（原版设计，本版完整保留）

- 只读官方返回的数据，不抓网页、不碰 Cookie、不摸账号密码
- 不消耗重置券、不执行任务、不碰你的对话正文
- 所有数据只存本地（`%LOCALAPPDATA%\CodexQuotaWidget\`），不上传任何服务器
